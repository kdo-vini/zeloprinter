# Instalação do Zelo Impressão para cliente final

Este material foi escrito para atendimento de linha de frente.

Objetivo: ajudar o cliente a instalar e configurar sozinho, sem termos técnicos.

## Como orientar o cliente

Fale sempre de forma simples:

- "baixe o arquivo"
- "abra o programa"
- "digite o código que aparece na tela"
- "escolha a impressora"
- "faça o teste"

Evite termos como:

- tray
- SmartScreen
- token
- localhost
- pareamento
- CORS

## Passo a passo para passar ao cliente

1. Baixe o instalador no computador onde a impressora está instalada.
2. Abra o arquivo baixado.
3. Na primeira vez, o Windows pode mostrar um aviso antes de instalar.
4. Oriente o cliente a continuar normalmente, avançar 2 vezes e clicar em instalar.
5. Quando a instalação terminar, peça para abrir o Zelo Impressão.
6. Explique que, se a janela fechar, o programa continua aberto no ícone perto do relógio do Windows.
7. Peça para voltar ao Zelo PDV ou ao ZeloChat.
8. Na parte de impressão, o cliente deve digitar o código de 6 números que aparece na tela do Zelo Impressão.
9. Depois disso, ele deve escolher a impressora correta.
10. Por fim, deve clicar para fazer o teste de impressão.

## Frases prontas

### Se o cliente acabou de baixar

"Agora abra o arquivo que foi baixado. Se aparecer um aviso do Windows na primeira vez, pode continuar. Depois é só avançar, avançar e instalar."

### Se o cliente instalou mas não vê a tela

"Sem problema. Procure o ícone do Zelo Impressão perto do relógio do Windows. Se não aparecer, clique na setinha para mostrar os outros ícones."

### Se o cliente já abriu o programa

"Perfeito. Agora volte ao PDV, clique em conectar impressora, digite o código que aparece na tela e depois escolha a sua impressora."

### Se o cliente pergunta se precisa de ajuda técnica

"Não precisa. Você mesmo consegue fazer. Eu vou te passar o passo a passo e você só vai clicando comigo."

## O que o cliente precisa confirmar no final

- o Zelo Impressão ficou aberto no computador
- o código foi digitado
- a impressora foi escolhida
- o teste saiu na impressora certa

## Observação importante

Se o cliente ainda não terminar essa configuração, o sistema pode continuar usando a impressão normal do navegador até o Zelo Impressão ficar pronto.
